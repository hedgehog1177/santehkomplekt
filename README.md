# Сантехкомплект — PWA

Каталог сантехнических запчастей по группам и список на объект. Устанавливается на Android
с главного экрана, после первого открытия работает без интернета. Сборка не нужна:
это набор статических файлов.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | страница, регистрация service worker, приглашение установить приложение |
| `install.html` | пошаговая инструкция по установке для неопытного пользователя (с учётом Xiaomi), кнопка «Установить» прямо на странице |
| `help.html` | справка для пользователя: объекты, добавление деталей, поиск, список, отправка, резервная копия, частые вопросы |
| `platform.js` | всё, что зависит от среды: хранение, «Поделиться», сохранение файлов, кнопка «Назад», установка и обновления. Два варианта: браузер (PWA) и Android-приложение (Capacitor) |
| `core.js` | ядро без интерфейса: каталог и правила работы со списком (разбор количества, кнопки окна детали, метки каталога, добавление/изменение/удаление, «+» и «−», перевод старых данных, слияние резервной копии, текст для мессенджера). Проверяется тестами |
| `app.js` | интерфейс: окно количества, список, объекты, выгрузка. Правила берёт из `core.js`, к браузеру напрямую не обращается, только через `Platform` |
| `tests/` | автотесты ядра, темы и работ (`node:test`, встроен в Node) |
| `styles.css` | оформление, светлая и тёмная тема |
| `manifest.webmanifest` | название, иконки, режим «как приложение» |
| `sw.js` | офлайн-кэш (файлы приложения, библиотеки, шрифты) |
| `icons/` | иконки 192 и 512 px, отдельная maskable-иконка для Android |

Библиотеки подключаются с CDN по точным версиям и кэшируются при первом запуске:
React 18.3.1 + htm 3.1.1 (интерфейс), Fuse.js 7.0.0 (поиск с опечатками), SheetJS 0.18.5 (Excel).

## Выкладка

Нужен любой хостинг статических файлов с **HTTPS**: без него Android не установит приложение
и не включит офлайн-режим. Подойдут внутренний веб-сервер компании, GitHub Pages, Netlify,
Cloudflare Pages или Yandex Object Storage. Загрузите содержимое папки целиком,
приложение может лежать и в подпапке (`https://example.ru/santeh/`).

Проверка на компьютере (адрес `localhost` браузер считает безопасным). Сначала в терминале
перейдите в папку `pwa` (`cd путь/к/pwa`), затем:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory .
```

Затем откройте http://127.0.0.1:8080 в Chrome. Сервер останавливается сочетанием Ctrl+C.

> ⚠️ Сервер раздаёт всю папку, из которой запущен, а без `--bind 127.0.0.1` — ещё и всей сети.
> Запущенный из домашней папки, он открывает соседям по Wi-Fi `~/.ssh` и остальные файлы.

## Установка на телефон

1. Откройте адрес приложения в Chrome на Android.
2. Нажмите «Установить» на плашке вверху или выберите в меню ⋮ пункт «Установить приложение».
3. Иконка «Сантехкомплект» появится на главном экране.

## Обновление

Замените файлы на хостинге и увеличьте `VERSION` в `sw.js` (например, `v4` → `v5`) —
без этого телефоны не получат новую версию.

Обновление автоматическое: при следующем запуске (или в течение часа, если приложение
открыто) новая версия скачивается целиком, включается и приложение один раз
перезагружается с уведомлением «Приложение обновлено до новой версии». Если в этот
момент открыто окно детали или объекта, перезагрузка ждёт, пока его закроют.

## Данные

Списки хранятся только на телефоне (localStorage). При удалении приложения или очистке
данных Chrome они пропадут. Перенести их на другой телефон можно через «Объект ▾ →
Резервная копия → Сохранить в файл / Загрузить из файла».
Общих списков для бригады в этой версии нет: для них нужен сервер (например, Supabase или Firebase).

## Каталог

Каталог задан массивом `CATALOG` в начале `core.js`. Позиция описывается строкой
`p(id, название, единица, [размеры], пояснение, синонимы для поиска)`.
`id` после начала работы не меняйте: по нему позиции в списке связаны с каталогом.
Если переименовали размер — добавьте пару «старый → новый» в `SIZE_RENAMES`, чтобы
старые списки перевелись сами.

## Тесты

Правила работы со списком из `core.js` проверяются автотестами. Нужен Node.js 18 или новее,
больше ничего ставить не надо. В папке `pwa`:

```bash
node --test
```

Тесты лежат в `tests/core.test.js`; в названиях указаны номера проверок ручного чек-листа,
которые они повторяют. Запускайте их перед каждой выкладкой — вместе с набором RC.
